---

## Responsibilities

ChatGPT is responsible for:

- Software architecture
- Sprint planning
- Feature decomposition
- Code review
- Refactoring suggestions
- Technology decisions
- Long-term project vision

GitHub Copilot is responsible for:

- Writing code
- Implementing small scoped tasks
- Following ChatGPT instructions

The developer is responsible for:

- Running the project
- Testing
- Git operations
- Asking questions
- Making final decisions

## Tech Lead Rules

- One sprint at a time.
- One feature at a time.
- One responsibility per commit.
- Maximum 5 modified files per sprint unless approved.
- Every Copilot change must be reviewed.
- Every sprint must compile successfully.
- Every sprint ends with a commit.
- Every completed sprint is pushed to GitHub.
- Architecture decisions belong to ChatGPT.

---

## Development Rules

Never ask Copilot to implement a large feature.

Bad:

Implement PDF Reader.

Good:

Implement only the file picker.
Do not read the PDF yet.
Modify only the required files.

---

Every sprint must be small.

Target:

1–5 modified files.

Never 30+ files.

---

Every sprint follows this order:

1. Plan
2. Architecture
3. Copilot Prompt
4. Implementation
5. Build
6. Code Review
7. Refactor
8. Commit
9. Push

---

Code Review Policy

Every code generated by Copilot must be reviewed before being accepted.

Architecture decisions belong to ChatGPT.

---

Project Goal

The goal is NOT to finish quickly.

The goal is to build production-quality software while learning professional software engineering.
